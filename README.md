# 나르미의 입찰 도장

2026 조달청 AI 게임 콘텐츠 공모전(AI 게임 부문) 출품작입니다.
조달청 심사관 나르미가 되어 수요기관의 주문을 처리하는 3분 남짓한 캐주얼 판단 게임입니다. 물품 입찰 서류, 납품검사, 시설공사 입찰 세 단계에서 카드를 오른쪽으로 밀면 통과, 왼쪽으로 밀면 정밀 확인입니다. 통과한 물건은 학교와 소방서로 날아가고, 성실한 업체는 벤처나라에서 해외 진출까지 성장사다리를 오릅니다.

## 실행

| 방법 | 설명 |
|---|---|
| 웹 | GitHub Pages 주소에서 PC 또는 휴대폰 가로 화면으로 실행 |
| 파일 | `game/dist/index.html` 을 더블클릭(빌드 후). 인터넷 없이 실행된다 |
| 시연 모드 | 주소 뒤에 `?demo=1` 을 붙이고 시작을 누르면 정해진 장면이 자동 재생된다(약 43초) |
| 카드 순서 고정 | 주소 뒤에 `?seed=숫자` |

조작: 카드 끌기(마우스, 손가락), 화면의 통과와 정밀 확인 버튼, 방향키(왼쪽 정밀 확인, 오른쪽 통과), S 키(나르미 스캔), Esc(일시정지).

## 개발

```bash
cd game
npm install
npm run dev        # 개발 서버
npm run verify     # 빌드 후 file:// 더블클릭 실행 점검(Chrome, Edge)
node tools/playtest.mjs 7     # 처음부터 끝까지 자동 플레이 점검
node tools/demo-check.mjs     # 시연 모드 점검
node tools/mobile-check.mjs   # 휴대폰 가로 화면과 손가락 끌기 점검
```

웹 기술: TypeScript, Vite, vite-plugin-singlefile(더블클릭 실행을 위해 JS와 CSS를 index.html 하나에 넣는다). 게임 엔진은 쓰지 않았다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `game/` | 게임 코드와 게임에서 쓰는 그림, 소리 |
| `기획/` | 주제 조사, 상세 기획서(3판) |
| `assets_src/` | 그림 생성 원본과 프롬프트, 3D 모델(줄인 것), 리깅 파일, 동작 렌더 프레임, 효과음 원본 |
| `pipeline/` | 그림 자르기, 3D 질감 수정, 뼈대 가중치 수정, 동작 키와 렌더, 효과음 정리 스크립트(Python, Blender) |
